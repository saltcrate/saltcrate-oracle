Pay-per-call web intelligence MCP server — fetch pages, check links, detect changes, verify claims.

- **Tools:** `fetch`, `check_link`, `check_change`, `verify`

This repo hosts the LobeHub plugin manifest (`lhm.plugin.json`) pointing at the hosted MCP endpoint.
